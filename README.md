# react-vite-admin-ts-shadcn-best-practice-skill

Coding conventions for Vite + React + TypeScript + shadcn/ui admin/console projects.

Covers: directory structure, type naming (VO/QO/DTO), service layer, TanStack Query hooks, page component patterns, auth, reusable components, and naming conventions.

## Usage

Install via [skills.sh](https://skills.sh):

```bash
npx skills add huyq/react-vite-admin-ts-shadcn-best-practice-skill -g
```
